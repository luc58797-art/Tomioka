# Sistema de atualização Tomioka

O arquivo version.json informa ao aplicativo qual é a versão mais recente.

Campos:

- version: versão atual
- name: nome do aplicativo
- apk: endereço do APK atualizado
- changelog: alterações da versão

Formato de versão:

MAJOR.MINOR.PATCH

Exemplo:

1.0.0
1.1.0
1.1.1
2.0.0
